# Ordrum · 瑞典语单词室

Rivstart A1/A2 Ordkort 学习网页与 iPhone 主屏幕 App，含 20 章、1,332 张词卡、英文释义和词形，以及 1,065 段瑞典语合成读音。

## 在线与 iPhone

GitHub Pages 地址：[Ordrum](https://silunzh.github.io/ordrum/)。Mac 双击 `启动网页.command` 可继续使用 http://127.0.0.1:8765。两种入口使用相同网页和同步机制，不需要旧 Sites 账号窗口。

学习记录保存在设备，并自动同步至独立的 **私有** [silunzh/ordrum-progress](https://github.com/silunzh/ordrum-progress) 仓库的 `progress.json`。此公开代码仓库不保存个人学习记录或访问令牌。

首次使用，进入「设置 → 同步设置」，填写 GitHub 用户名、私有进度仓库名和仅限该仓库的 fine-grained personal access token。令牌只需 Repository permissions → Contents: Read and write；不要授权个人主页或其他仓库。详细配置和同步规则见 [docs/SYNC.md](docs/SYNC.md)。勾选「在此浏览器记住连接」后，重新打开可自动连接；不勾选只在当前会话保留。令牌仅发给 GitHub API，不进入学习备份或代码。请直接在应用中填写，不要发送到聊天。

连接同一账号和同一私有仓库后，任务、错题、词条修改、复习记录、计划会话、计划设置和学习位置会自动合并，以「学习进度已同步」为完成标志。学习变化延迟几秒上传；打开或返回页面时同步，前台每两分钟检查另一设备的更新。离线修改留在本机，联网后自动合并。首次迁移可明确选择合并此设备的现有记录；之后换账号或仓库仍保持隔离。

iPhone 在 Safari 打开新网址，点「分享」→「添加到主屏幕」。主屏幕 App 与 Safari 可能使用不同存储，两处都需配置同一个私有仓库。无需保持额外窗口打开。界面和词库准备好后可离线使用；音频在联网播放时逐步缓存。iPhone 可能需要先点按播放按钮才允许自动发音。

## 学习

- 在书架选择 Rivstart 或错题本，再勾选章节，用预览模式浏览或搜索；可将所选章节或整本书创建为独立任务。
- 翻开释义后瑞典语仍然可见，文字可选中复制；勾选自动读音后，返回正面会播放。可按需展开同义词、反义词、瑞典语音标和例句，详见下文。
- 听写每到新词自动播放。回车先检查，答对后再次回车进入下一词，答错后再次回车清空重试并播放。
- 动词词形按命令、不定、现在、过去、完成排序。å、ä、ö 在听写中分别判定。
- “学习任务”支持继续、重命名、归档、重置、删除；“错题本”支持筛选、搜索、批量重练、掌握或删除。
- 卡片位置、翻面状态、听写草稿和结果都会保存。错词重练可返回原学习位置。
- 可编辑词条并导出、导入完整学习记录。导入前先预览变化，确认后自动保留恢复前备份；重要记录仍建议定期手动导出。

## 按计划学习与间隔复习

右上角「计划学习」进入独立页面，主页继续用于自由学习与学习任务。三种方法默认围绕每天约一小时安排不同的新词与到期复习词：

| 方法 | 新词 / 到期复习 | 每日不同词目标 | 流程 |
| --- | ---: | ---: | --- |
| 分组主动回忆 | 30 / 90 | 120 | 新词预览 → 主动翻卡 → 难词听写 |
| 听写巩固 | 20 / 80 | 100 | 新词预览 → 首次听写 → 错词重练 |
| 快速交错复习 | 40 / 160 | 200 | 新旧词交错翻卡 → 难词回看 → 听写抽查 |

100–200 指新旧合计的不同词，不代表每天掌握同等数量的新词。满额粗估约 54–60 分钟（含休息），是可编辑的工作量起点；可修改方法、每日上限、10–180 分钟预算、10–25 词分组、书籍/章节/错题本范围和复习间隔。到期词不足时按实际数量安排，不自动增加新词凑数。已有设置保留，点击方法预设后才更新默认值。

每组结束可休息或继续，暂停、返回书架及重新打开均保留当前进度。已开始的一轮冻结词序与方法；调整设置用于下一轮。提前结束也保留已完成的记录。计划分别显示接触词数、翻卡自评与听写首答，避免把熟悉感当成拼写正确率。

成功后的默认间隔为 1、3、7、14、30 个日历日；听写预设为 1、2、5、12、30。答错、看答案或翻卡选「再记一次」后，约 10 分钟再安排。每轮每词只采纳首次结果，辅助重试不会抹掉首次错误；同一天重复成功不会连续升级，提前练习不会推迟原到期日。

每日限额跨所选范围计数，切换书籍/章节不会重新得到一份名额。记录从启用后的实际操作开始，不用以前的掌握标记补造历史。计划会话、偏好和复习记录随学习进度同步。历史达到容量时保留已有和未上传记录，明确暂停收集新事件；导出本身不会释放容量。详细默认值、计时和记录规则见 [计划学习说明](docs/REVIEW.md)。

## 书架、错题与设置

- 错题本是书架中可选择的一本书。其章节包括全部错词、今天错词、本周错词和每组最多 30 词的固定单元；可像 Rivstart 一样选择章节、切换学习模式、创建任务。选择错题本后显示「管理错题本」。
- 今天、本周按本机日历统计，周一开始；没有实际答错日期的历史词保留在全部错词，已掌握的错词仍可查看。动态分类自动变化，固定单元保留分组。
- 在管理页点击「整理今天错词」「整理本周错词」或「整理全部错词」，把未分组词整理成单元。重复整理不重复建组；新词补入未满单元，不清空原错误记录。固定单元可重命名或删除分组，删除分组保留错词和学习历史；错词本身仍可筛选、搜索、批量重练、掌握或删除。
- 顶部「设置」整合同步设置、发音、外观、档案和 iPhone App。同步标签显示目标、最近成功核对、本机待上传变化及重试或重新连接入口；变化数量按记录计算，不是单词数或答题次数。
- 从档案导入或恢复点恢复前，先预览增改删并自动保存当前记录。恢复点只在此浏览器保存，按账号与书籍隔离，每组保留最近一次、最多 6 组；并不代替手动导出。若无法保存恢复前备份，不更改当前记录。
- 外观可选浅绿、纸白、夜读，以及紧凑布局；只保存在此浏览器，不改变其他设备。手机的章节选择默认折叠，可点「选择章节」展开。
- [功能决策记录](docs/ROADMAP-20261021.md) 保留原始建议及实现状态；已选择的同步与恢复、间隔复习两项现已实现。

## 临时扩展词义

翻开卡片后，可依次切换「同义词」「反义词」「读音版本」「例句」，显示顺序固定。先查询当前瑞典语词形，找不到对应内容时使用已有原形补查；不猜测未知词形。同义词、反义词可直接点开查词，读音版本只保留明确标记为瑞典语的音标。卡片不展示额外出处页脚，必要引用集中在「设置 → 档案」。

第一次展开时联网查询 Wiktionary 的瑞典语区。社区词典不保证每个词有相应资料，缺少时显示「暂无」，不补造。查询不发送任务、错词、答案或同步令牌。内容与开关只保留当前页面内存，不写入词条修改、备份或同步；已有缓存可离线查看，没有缓存则需联网。词库原有释义与瑞典语音频照常可用。来源边界与许可见 [临时扩展说明](docs/WORD-EXTRAS.md)。

## 本地开发

网页源文件在 `public/`。本地静态服务只需要 Node.js：运行 `npm run local`，或双击 `启动网页.command`，无需安装依赖。GitHub Pages 和本地网页直接调用 GitHub API，不经过本地服务器转发令牌。

本地学习使用固定的 127.0.0.1:8765，保留原有浏览器进度。启动器会加载当前脚本以避开旧离线缓存。更新后请关闭原启动窗口，再重新启动；不要清理浏览器记录。

运行 `npm test` 验证学习、账号隔离、迁移中断恢复、GitHub SHA 冲突和离线缓存。发布前运行 `node scripts/version-pwa.cjs`。`node scripts/export-pages.cjs` 生成 `outputs/github-pages/`，无需项目依赖。目录说明见 [docs/PROJECT.md](docs/PROJECT.md)。

旧 Sites 的 `app/`、`db/`、`drizzle/`、`worker/`、`lib/` 及相关测试暂作历史迁移参考，不参与当前静态发布；不应重新发布旧服务或把数据库、备份和运行目录上传到公开仓库。

## GitHub Pages 发布

独立公开仓库：[silunzh/ordrum](https://github.com/silunzh/ordrum)。`.github/workflows/pages.yml` 在 `main` 更新后检查同步逻辑，再发布静态网页。网站、安装和 Service Worker 均只在 `/ordrum/` 下，不修改个人主页仓库、根目录或域名。

导出包排除旧账号桥、服务器、数据库、备份、凭据与本机状态。私有进度仓库应始终保持 Private，不启用 Pages。

## 数据与许可

词卡来自用户提供的 PDF。英文词典资料来自 Folkets lexikon，词形资料来自 SALDO，并包含人工校订。来源和许可见 [DICTIONARY-SOURCES.md](public/DICTIONARY-SOURCES.md)。保持卡片 ID、原始瑞典语、章节及来源记录不变。
